# Lorebooks and scenarios

## Lorebooks

A lorebook holds facts about your world that should only reach the model when they matter. Each **entry** has
**keywords** and **text**: when a keyword appears in the recent conversation, the text is added to the prompt.

Make one in **Library → Lorebooks → New lorebook**, or it arrives inside a character card you import.

Per entry you can set:

- **Keywords** (and optional **secondary keywords** with *selective*: both must appear);
- **Always on**, for entries that should always be in the prompt;
- **Priority**, for which entries go first when the lore budget is full;
- **Case sensitive**, and a **memo** that is never sent to the model.

A lorebook can belong to a character (it travels in their card) and a chat can use several. The inspector's **Lore**
tab shows which entries the last reply triggered.

A lorebook (and a scenario) can have a **banner** picture, best at 770 × 110, shown behind its header and on its Library
card.

## Scenarios

A scenario is a reusable situation: a block of scene text and an optional opening message, for starting the same
character in different stories. Choose one when you start a chat; it replaces the character's own scenario and first
message for that chat.

Make one in **Library → Scenarios**.
