## Findings

- **[fixed]** A chat with no model (the demo chats, imports) took the first model in the list and saved it, ignoring the
  default model set in Settings: the demo chat opened on Anthropic with DeepSeek chosen as default. The header now
  prefers the default model (`ChatHeader`, `firstAvailable`).
- **[fixed]** Chat export's "Memory (facts and Core Memory)" called `/api/drawer/facts?chatId=…` without `subject`, which the
  route refuses (400), so the exported memory had no facts. It now takes the whole memory graph (`/api/drawer/graph`).
- **[fixed]** The chat header's model picker had no accessible name (a screen reader said "combobox"); now "Chat model".
- Checked: a real turn on DeepSeek V3.1 (~10 s), and the reply recalled "Biscuit" from the previous message. Memory is
  written when the exchange settles (next message, or 2 min idle), by design.
- Checked: memory after two turns: 6 facts and a Core Memory summary from the local model. Some facts are loose
  ("player works_at harbour" when Nora only walks there; "night_shift lives_at port_ellery").
- **[idea]** Fact quality on the 4B memory model is uneven (see above). A one-line hint in the extraction prompt
  ("works_at only for a job") or a larger model when the GPU is free would help; measure with `npm run eval:gate`.
- Checked: `/image June at the microphone…`: the director wrote the prompt and krea2-photo drew it, about 90 s in all; the
  look tags held (hoops, glasses up in her hair, cardigan).
- **[idea]** The director's prompt included "June Okafor" by name, which its instructions forbid (image models don't
  know names). Harmless here; could be stripped after the fact by removing the character's name from the prompt.
- Checked: Play on June's reply made the audio in her voice with the narrator, about 40 s cold, kept as an asset.
- **[fixed]** A text reply opened by echoing the user's message in brackets: "(thx for the song, biscuit
  approves)\n\nOf course…". History marks texts "(by text) …" and the model copied the habit. `cleanChannelReply`
  (channel.ts) drops a leading label and a bracketed opening that is mostly the user's words (the character's own
  aside stays). The texting prompt now also says never to repeat or quote the message.
- Checked, group chat (Storm on Quay Street): opened on `gpt-oss:20b` (the same no-model bug, fixed above). Addressing
  June by name made June answer; "Elias Brandt speaks now" made Elias answer, in character; sending Elias away hid the
  reply picker and recorded him in `absentIds`; bringing him back cleared it.
- **[idea]** Characters sometimes answer in the first person ("*I slide onto a stool…*") when the user writes
  "*I wring out my scarf*", although the cards are written in the third person. A line in the group instructions
  ("narrate your own actions in the third person") would keep the voice consistent.
- Checked: all 12 sections open with their heading and no console errors; Gallery groups the new render under its chat.
- **[fixed]** At 375 px the Chats and Archive header (search box plus New Chat) ran 100 px past the screen; it now wraps
  and the search takes the row. Presets kept its preset list beside the editor on a phone, pushing "Reset to Defaults"
  and the slider values off the edge; the list now sits above the editor below `md`.
- Checked at 375 px: Groups, Lorebooks, Scenarios, First messages, Image Studio, Gallery, Workflows, Settings and an
  open chat have nothing past the edge. The Library's tab row scrolls sideways, as it is meant to.
- Checked: every inspector tab (Character, Core Mem, Memory, Lore, Web, Images) opens with no errors; Lore shows Port
  Ellery injected at 116 of 500 tokens.
- **[fixed]** The inspector's Facts list asked only for the character's facts, so everything they learned about you (5
  of the 9 facts here: Biscuit, the harbour walks, the market stall) could not be seen, corrected, pinned or locked.
  Facts now has "About June / About you"; adding a fact goes to whichever is shown.
- Not a bug: relationship stats stayed empty after four friendly exchanges. The extraction prompt reserves stat changes
  for real emotional moments by design (see the soak notes in AGENTS.md).
- Checked: Branch from June's "Biscuit" reply made an exact branch (5 messages, not flagged approximate) whose memory is
  as of that message ("works_at harbour", before it was superseded by "ferry_terminal"); deleting the branch purged its

## Ideas, by value (second pass: done)

1. **[fixed]** Message actions appeared only on hover, so a touch screen never showed Play, Branch, Edit or "image of
   this scene". One rule in `globals.css`: on a device with no hover, every hover-revealed control is shown (messages,
   fact pin/lock, gallery and preset buttons, chat rename/delete). Checked in phone emulation (opacity 1) and in Chrome
   with a mouse (still hidden until hover).
2. **[fixed]** Fact quality: the extraction prompt now says works_at is only for a job or workplace and lives_at only for
   a person or an animal (the two loose facts seen). Extraction fixtures regenerated on purpose.
3. **[fixed]** Names in picture prompts: `withoutNames` (imageLook.ts) takes the people's names out of the director's
   prompt: full names anywhere, a first name only as a tag of its own or a possessive ("their hands"), so "a June
   evening" stays. Checked: an `/image` in a test chat came back with no names.
4. **[fixed]** First-person narration: the cause was the system prompt itself, "Write in first person", which models
   read as "narrate actions with I". It now says to speak as the character in the style of their earlier messages
   (third person when that is how they are written). Checked: "*I stumble in out of the rain*" got "*He takes the coat
   from her…*". Applies to group scenes too.
5. **[fixed]** Memory timing: Facts' empty state now says memory is written when the exchange settles (next message,
   or two minutes after the reply); Relationships' says only real emotional moments move it.
6. Not needed: an "About you" view for Relationships and the Web. Relationships already lists how the character feels
   about you (character → you), and the Web already has you as a node.
7. Accepted: adding the demo to an existing install skips characters that already exist.

Found on the way:

- **[fixed]** `npm run eval:gate` reported "exchanges: 0" and passed: on this Windows checkout the transcripts have CRLF
  line endings and its pattern only matched `
`. It now normalises them, and finding no exchanges is a failure. Now
  499 exchanges, 312 productive, the gate skips none of them.
- **[fixed]** The default model and other chat-model settings lived only in the browser, so clearing site data lost
  them. The server now keeps a copy (`/api/provider-settings`); checked by clearing the browser's data and reloading:
  the default model came back. (How it had been lost before this build was not found; it now cannot be lost that way.)
- **[fixed]** Deleting a chat kept its pictures without saying so. The dialog now says where they go and offers "Also
  delete its N pictures"; checked on a test chat (the chat and its page were both removed).
