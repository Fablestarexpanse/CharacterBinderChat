because "done" that cannot be checked is how the gaps in the audit got there.

## Working rules for this plan
- One commit per item, each with its tests, and `tsc`, `lint`, the production build and the full test suite green.
- Anything touching data (backup/restore, delete) is verified against a real database in a real browser, not only unit tests.
- Nothing is marked ✅ until its acceptance line has been observed.
